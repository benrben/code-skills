# User-facing responses

Use the `agent-response` skill for every user-facing reply in this repository.
Read [the skill](skills/agent-response/SKILL.md) and its
[text guidance](skills/agent-response/references/text.md) when starting work,
then apply them throughout the conversation, including progress updates,
questions, coding summaries, and final answers. This is a standing requirement;
do not wait for an explicit `$agent-response` request or implicit skill selection.

Default to clear, natural prose. Use diagrams, interactive HTML, or explainer
videos when they help the user understand or when explicitly requested. Keep
brief replies brief and preserve required formats, verbatim content, and code.
